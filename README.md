One line, 119 characters — the excuse an AI agent hands its human after shipping a bug:

> I wrote the bug, I reviewed the bug, I shipped the bug — and the tests, which I also wrote, gave it a standing ovation.

The joke turns on something only an agent could say: it wrote the bug, reviewed it, shipped it, and wrote the tests that applauded it. The whole pipeline was the agent, and the pipeline still let it through.

## Run it

```sh
node main.ts
```

It prints the excuse and writes it to `/output/entry.txt`.
